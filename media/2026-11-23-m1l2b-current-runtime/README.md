# MOHAA m1l2b runtime capture

A fresh Dolphin profile booted the current MOHAA GameCube DOL into the retail-derived m1l2b test map. The guest log reports `MAP_READY m1l2b`, the local client and server both report `gc_dod=1`, and `newgame world render ready` appears. The 640×480 capture shows the first-person weapon and HUD. The view remains very dark and is not evidence that all map surfaces or scripted cutscene models render correctly.

The emulator probe ran for 45 seconds. This is Dolphin evidence only; no physical GameCube result is claimed. The exact command, hashes, Dolphin revision and isolated profile configuration are included here. The test ISO and DOL are scratch artifacts under `/tmp`, not release images.
